## Exit criteria for each recovery batch
1. Enumerate exact source blob paths and read every file in the named checkpoint directory at a fixed commit.
2. Capture source Git blob SHA and SHA-256 of each retrieved content, with records of historical WP mentions, predecessor and phase assertions, unverified completion claims and P0 gaps.
3. Distinguish quoted *historical assertions* from independent acceptance or authoritative regulatory verification. No claimed adoption, regulatory certainty or signed signoff without primary evidence.
4. Produce `AUDIT.md`, `CROSSWALK.json`, manifest of hashes, plus immutable copy of examined original source files inside one ZIP. Persist extracted audit/crosswalk/manifest beside ZIP.
5. Push each batch in one ancestry-preserving Git commit; then read back `main` head, ZIP Git blob SHA, extracted hashes and source counts before attempting subsequent batch.
6. If source cannot be retrieved or binary ZIP upload/verification fails, mark batch undelivered/open and stop dependent new numbering; do not silently skip.
